STANDAR KOLOM - PROJECT PETA TEMATIK QGIS
============================================================
Aturan Umum & Struktur Data Proyek
- Kolom kunci identitas wilayah: "name" (nama provinsi baku huruf kapital, 38 provinsi).
- Nama kolom: huruf kecil, tanpa spasi, menggunakan underscore.
- Format koordinat: GeoJSON WGS 84 (EPSG:4326), urutan [longitude, latitude].
- Angka: tanpa titik pemisah ribuan, desimal menggunakan tanda titik (.).
- Kolom bertanda [BPS]    = data asli dari publikasi/tabel BPS.
- Kolom bertanda [HITUNG] = dihitung melalui kalkulasi atribut (Field Calculator / Python).

------------------------------------------------------------
0. DATA DASAR / UMUM (Ada di semua layer peta)
   File Master: data_umum_2025.geojson & data_umum_2023.geojson
------------------------------------------------------------
name              teks      nama provinsi baku huruf kapital (kunci identitas)
latitude          desimal   titik koordinat lintang centroid provinsi
longitude         desimal   titik koordinat bujur centroid provinsi
layer             teks      nama layer provinsi asal
path              teks      path file sumber batas wilayah provinsi
luas              desimal   luas wilayah (km2)                        [BPS]
populasi          bulat     jumlah penduduk (jiwa)                    [BPS]
tahun             bulat     tahun referensi data (2025 atau 2023)

------------------------------------------------------------
1. PETA 1 - TINGKAT KEGEMARAN MEMBACA
   File Layer : 02_data_bersih/tingkat_kegemaran_membaca.geojson
   File Proyek: 03_peta_tematik/fatiya/tingkat_kegemaran_membaca.qgz
   Sumber     : BPS / Perpustakaan Nasional RI, 2025
   Tahun Data : 2025
------------------------------------------------------------
tgm               desimal   skor Tingkat Kegemaran Membaca total      [BPS]
tgm_pra           desimal   skor TGM kelompok pra-sekolah             [BPS]
tgm_saat          desimal   skor TGM kelompok saat bersekolah         [BPS]
tgm_pasca         desimal   skor TGM kelompok pasca-sekolah           [BPS]
selisih           desimal   selisih skor ("tgm_pasca" - "tgm_pra")    [HITUNG]

Catatan Peta 1:
- Kolom utama yang digunakan untuk simbologi peta tematik: "tgm".
- Pewarnaan menggunakan mode Graduated (skala 0 - 100).

------------------------------------------------------------
2. PETA 2 - BEBAN & KETERJANGKAUAN SEKOLAH
   File Layer : 02_data_bersih/kepadatan_sekolah.geojson
   File Proyek: 03_peta_tematik/fatiya/rata_rata_beban_murid_persekolah.qgz
                03_peta_tematik/fatiya/keterjangkauan_sekolah.qgz
   Sumber     : BPS data persebaran sekolah SD, SMP, SMA, 2025/2026
   Tahun Data : 2025
------------------------------------------------------------
sd                bulat     jumlah sekolah SD (Negeri + Swasta)       [BPS]
smp               bulat     jumlah sekolah SMP (Negeri + Swasta)      [BPS]
sma               bulat     jumlah sekolah SMA (Negeri + Swasta)      [BPS]
tot_sekolah       bulat     total unit sekolah ("sd" + "smp" + "sma") [HITUNG]
murid_sd          bulat     jumlah murid SD (Negeri + Swasta)         [BPS]
murid_smp         bulat     jumlah murid SMP (Negeri + Swasta)        [BPS]
murid_sma         bulat     jumlah murid SMA (Negeri + Swasta)        [BPS]
tot_murid         bulat     total murid ("murid_sd"+"murid_smp"+"murid_sma") [HITUNG]
beban_sekolah     bulat     rata-rata murid per sekolah:              [HITUNG]
                            round("tot_murid" / "tot_sekolah")
rasio_sekolah     desimal   sekolah per 10.000 penduduk:              [HITUNG]
                            ("tot_sekolah" / "populasi") * 10000
kep_sd            desimal   kepadatan SD per 1.000 km2 luas           [HITUNG]
kep_smp           desimal   kepadatan SMP per 1.000 km2 luas          [HITUNG]
kep_sma           desimal   kepadatan SMA per 1.000 km2 luas          [HITUNG]
kep_sekolah       desimal   total sekolah per 1.000 km2 luas          [HITUNG]

Catatan Peta 2:
- Kolom utama yang digunakan untuk simbologi: "beban_sekolah" (siswa/gedung)
  atau "rasio_sekolah" (sekolah per 10.000 penduduk).

3. PETA 3 - TINGKAT PENYELESAIAN PENDIDIKAN
   File Layer : 02_data_bersih/tingkat_penyelesaian_pendidikan.geojson
   File Proyek: 03_peta_tematik/fatiya/tingkat_penyelesaian_pendidikan.qgz
   Sumber     : BPS, Tingkat Penyelesaian Pendidikan Menurut Jenjang, 2023
   Tahun Data : 2023
------------------------------------------------------------
selesai_sd        desimal   persentase penyelesaian pendidikan SD (%) [BPS]
selesai_smp       desimal   persentase penyelesaian pendidikan SMP(%) [BPS]
selesai_sma       desimal   persentase penyelesaian pendidikan SMA(%) [BPS]
gap_sd_sma        desimal   kesenjangan SD vs SMA:                    [HITUNG]
                            "selesai_sd" - "selesai_sma"
gap_smp_sma       desimal   kesenjangan SMP vs SMA:                   [HITUNG]
                            "selesai_smp" - "selesai_sma"

Catatan Peta 3:
- Kolom utama yang digunakan untuk simbologi: "gap_sd_sma" atau "selesai_sma".
- Tahun data adalah 2023 (tahun survei resmi BPS).

4. PETA 4 - KETERSEDIAAN FASILITAS PENDIDIKAN DESA
   File Layer : 02_data_bersih/ketersediaan_fasilitas_pendidikan_desa.geojson
   File Proyek: 03_peta_tematik/fatiya/ketersediaan_fasilitas_pendidikan_desa.qgz
   Sumber     : BPS, Fasilitas Pendidikan Tingkat Desa & Jumlah Desa, 2025
   Tahun Data : 2025
------------------------------------------------------------
total_desa        bulat     jumlah total desa/kelurahan per provinsi  [BPS]
desa_sd           bulat     jumlah desa yang memiliki fasilitas SD    [BPS]
desa_smp          bulat     jumlah desa yang memiliki fasilitas SMP   [BPS]
desa_sma          bulat     jumlah desa yang memiliki fasilitas SMA   [BPS]
desa_smk          bulat     jumlah desa yang memiliki fasilitas SMK   [BPS]
desa_pt           bulat     jumlah desa berfasilitas Perguruan Tinggi [BPS]
cak_sd            desimal   persen desa berfasilitas SD (%):          [HITUNG]
                            ("desa_sd" / "total_desa") * 100
cak_smp           desimal   persen desa berfasilitas SMP (%):         [HITUNG]
                            ("desa_smp" / "total_desa") * 100
cak_sma           desimal   persen desa berfasilitas SMA (%):         [HITUNG]
                            ("desa_sma" / "total_desa") * 100
cak_smk           desimal   persen desa berfasilitas SMK (%):         [HITUNG]
                            ("desa_smk" / "total_desa") * 100
cak_pt            desimal   persen desa berfasilitas PT (%):          [HITUNG]
                            ("desa_pt" / "total_desa") * 100
cak_fasilitas     desimal   rata-rata persentase cakupan fasilitas:   [HITUNG]
                            ("cak_sd" + "cak_smp" + "cak_sma" +
                             "cak_smk" + "cak_pt") / 5

Catatan Peta 4:
- Kolom utama yang digunakan untuk simbologi: "cak_fasilitas".

5. PETA 5 - PERSEBARAN PERPUSTAKAAN TERAKREDITASI
   File Layer : 02_data_bersih/persebaran_perpustakaan_terakreditas.geojson
   File Proyek: 03_peta_tematik/fatiya/persebaran_perpustakaan_terakreditasi.qgz
   Sumber     : BPS / Perpustakaan Nasional RI, 2025
   Tahun Data : 2025
------------------------------------------------------------
total_perpus      bulat     jumlah total perpustakaan terakreditasi   [BPS]
p_sekolah         bulat     total perpustakaan sekolah terakreditasi  [BPS]
p_umum            bulat     total perpustakaan umum terakreditasi     [BPS]
p_pt              bulat     total perpustakaan perguruan tinggi akred [BPS]
p_khusus          bulat     total perpustakaan khusus terakreditasi   [BPS]
a_sekolah         bulat     perpustakaan sekolah terakreditasi A      [BPS]
a_umum            bulat     perpustakaan umum terakreditasi A         [BPS]
a_pt              bulat     perpustakaan perguruan tinggi akreditasi A[BPS]
a_khusus          bulat     perpustakaan khusus terakreditasi A       [BPS]
perpus_a          bulat     total perpustakaan terakreditasi A:       [HITUNG]
                            "a_umum" + "a_khusus" + "a_sekolah" + "a_pt"
persen_a          desimal   persen perpustakaan terakreditasi A (%):  [HITUNG]
                            ("perpus_a" / "total_perpus") * 100

Catatan Peta 5:
- Kolom utama yang digunakan untuk simbologi: "persen_a" atau "total_perpus".
